# Phase 8.1: options for a quieter measurement setup

Nothing below was applied. "Apply" and "Undo" are the commands that would be used; commands that need a password go to your own terminal tab. Measured evidence is in `results/p8_1_findings.md` and `results/p8_1_idle_table.md`. Benefits marked "not measured" are untested.

| # | option | risk | apply | undo | evidence |
|---|---|---|---|---|---|
| 1 | **Hands-off launch with a settle pause (recommended).** Start the measurement from a Terminal tab, pause 60 s, take a pre-flight idle set that must satisfy V8, then run; nobody uses the desktop, and the assistant produces no output while it runs (one silent watcher only). | The machine is unusable for the run (about 40 minutes for the Phase 6 matrix); an interactive reply during the run contaminates windows, which V8 then flags and re-runs (cost: time). | `sudo bash -c 'sleep 60; bash scripts/bench.sh idle 10; bash scripts/bench.sh run'` (final form to be fixed in the Phase 8.2 design) | Ctrl-C in the tab, then `sudo pkill -f 'build/(loader\|classifier\|baseline_sniffer)'` and `sudo bash scripts/lab_up.sh down` if the lab should go | settled set `0.126` against quiet calibration `0.131` (3 windows only) |
| 2 | Close Firefox before a run (frees about 1.2 GB for the content process alone and relieves the swap pressure). | Open tabs; Firefox restores the session on restart. | close the Firefox window | start Firefox | not measured; swap usage shown in the probe |
| 3 | Stop periodic timers for the run: `sysstat-collect`, `apt-daily`, `apt-daily-upgrade`, `fwupd-refresh`, `motd-news`, `man-db`. | Housekeeping is delayed; the stop does not survive a reboot. | `sudo systemctl stop sysstat-collect.timer apt-daily.timer apt-daily-upgrade.timer fwupd-refresh.timer motd-news.timer man-db.timer` | `sudo systemctl start sysstat-collect.timer apt-daily.timer apt-daily-upgrade.timer fwupd-refresh.timer motd-news.timer man-db.timer` | not measured; none fired inside the idle windows of this phase |
| 4 | Separate text login (tty3) or an ssh login from another machine, run the benchmark there while the desktop is idle. | Not available now (you said so). Switching virtual terminals under VirtualBox with Wayland is UNVERIFIED here. Equivalent to option 1 without the Claude app in the foreground. | Ctrl+Alt+F3, log in, `sudo bash scripts/bench.sh run` | Ctrl+Alt+F2 (the graphical session is on `tty2`) | step 2 variant not run |
| 5 | Restrict the desktop to some cores with a cpuset (`user.slice`). | Cores 0 and 1 are the V8 canaries, so confining the desktop to them defeats the canary rule and needs a design amendment; whether the `cpuset` controller is delegated here is UNVERIFIED. | `sudo systemctl set-property --runtime user.slice AllowedCPUs=0-1` | `sudo systemctl set-property --runtime user.slice AllowedCPUs=` | not tested; not recommended |
| 6 | Switch to a text-mode target. | Ends the graphical session and the Claude desktop app this work runs in; rejected before in D6.9. | `sudo systemctl isolate multi-user.target` (only with your explicit go-ahead) | `sudo systemctl isolate graphical.target` | not needed given option 1 |
| 7 | Turn off GNOME animations. | A persistent user setting (dconf), so it would need your approval. | `gsettings set org.gnome.desktop.interface enable-animations false` | `gsettings reset org.gnome.desktop.interface enable-animations` | not measured; not needed |

## Recommendation

Option 1, with option 2 as an extra if swap pressure shows up again. It needs no system change, matches the only configuration that was measured as quiet, and keeps V8 as the guard. The Phase 8.2 design should make the settle pause and the pre-flight idle set part of the launcher and should say that a failed pre-flight stops the run instead of continuing. Option 3 can be added if V8 flags windows that coincide with timer activity.
